## 🌿 A calmer way to stay organized

TaskFlow brings your daily tasks, deadlines, and projects into one clean desktop application.

A mountain-inspired background, muted colors, and subtle transitions help create a comfortable space for focused work.

## ✨ Your workspace

| View | What you can do |
|:---|:---|
| ☀️ **Today** | Focus on the tasks that matter today. |
| 🗓️ **Upcoming** | See approaching deadlines and plan ahead. |
| 📅 **Calendar** | Explore your schedule in month and week views. |
| 📋 **Board** | Move tasks between **To do**, **In progress**, and **Done**. |
| 🏷️ **Categories** | Organize tasks with custom categories and colors. |
| ⚙️ **Settings** | Manage notifications, motion preferences, and updates. |

## 🧩 Small details that help

- **Quick Add** — capture a task while it is on your mind.
- **Subtasks** — break larger tasks into manageable steps.
- **Recurring tasks** — schedule work that repeats.
- **Importance & urgency** — rate each from **1 to 5**.
- **Reminders & snooze** — receive reminders while TaskFlow is running.
- **Search & quick actions** — find tasks and navigate your workspace.
- **Drag & drop** — update task status directly on the Board.
- **Undo** — reverse supported actions.

## 📥 Download & install

1. Open the **Releases** section of this repository.
2. Choose the latest available release.
3. Download **`TaskFlow-Setup-X.Y.Z.exe`**.
4. Run the installer and follow the instructions.

> 🖥️ **Requirements:** Windows 10 or later, 64-bit.  
> 🐍 **No Python installation required.**

## 🔄 Keep TaskFlow up to date

In versions that support updates, open:

**Settings → Updates → Check for updates**

When a newer version is available:

1. Download the update.
2. Save any unfinished work.
3. Select **Install and close**.

You can also install the latest setup from Releases into the same installation folder.

---

## 🔒 Your tasks stay on your computer

Tasks and settings are stored locally:

```text
%LOCALAPPDATA%\TaskFlow\data
```

- Your planner data is **not uploaded to this repository**.
- Synchronization between computers is **not supported**.
- Upgrades preserve saved tasks and settings.
- Updates installed through the application create a database backup before installation.
